# FICA — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ferramenta web estática (um `index.html`, offline, GitHub Pages) que lê o log e a conclusão de atividades exportados do Moodle e mostra, em quatro abas, quem pode precisar de contato, o diário semanal de acessos, a comparação entre turmas e acesso × conclusão; mais um script Node que gera as tabelas e figuras do TCC com o mesmo cálculo.

**Architecture:** Lógica pura em módulos ES (`src/core.js`, `src/charts.js`, `src/demo.js`) usados no Node (testes e script do TCC) e no navegador. `src/ui.js` desenha as telas. `build.mjs` junta template, CSS e JS num único `index.html` com CSP por hash. Sem dependências npm.

**Tech Stack:** JavaScript (ES2022), HTML, CSS, SVG gerado como string; Node ≥ 20 só para testes (`node --test`), build e script do TCC.

**Spec:** `docs/superpowers/specs/2026-11-23-fica-design.md` (ler inteiro antes de começar). Contexto de produto: `PRODUCT.md`. Direção visual: `.impeccable/surfaces/index-html.md` e o esboço escolhido `.impeccable/sketches/d-abas.html`.

## Global Constraints

- **Privacidade dos dados reais:** nunca abrir, ler, imprimir ou copiar arquivos de `C:\dev\projetos\Pessoal\tcc_posEAD_EPT\` (contêm nomes de estudantes). Todo teste e exemplo usa dados sintéticos gerados por `src/demo.js`. O script do TCC será rodado com dados reais pela autora/Claude, não pelo implementador.
- `.gitignore` bloqueia `*.csv` exceto `exemplos/*.csv`; também `saida/`, `node_modules/`.
- Zero dependências npm. `package.json` com `"type": "module"` e scripts `test` (`node --test`), `build` (`node build.mjs`).
- `index.html` final: nenhuma URL `http://` ou `https://` carregada (links `<a href>` para fora são permitidos só na ajuda); nenhum atributo `style="…"` (a CSP bloqueia); CSP meta exatamente: `default-src 'none'; script-src 'sha256-…'; style-src 'sha256-…'; img-src data:; media-src 'self'; connect-src 'none'; form-action 'none'; base-uri 'none'`.
- Toda a interface em português do Brasil. Nunca exibir endereço IP (descartar a coluna no parse).
- Texto nunca associa pouco acesso a desinteresse, preguiça ou dificuldade de aprendizagem. Lembrete fixo na triagem: "Acesso ao Moodle não é o mesmo que participação ou aprendizagem. Use estes sinais para conversar com o estudante."
- Visual do AVA: verde `#2e8b57`, verde-escuro `#1f5f3b`, creme `#f4f1dc`, creme-escuro `#efeccf`, borda `#d9d4b8`, texto `#1f2a24`, cinza de contexto `#9aa0a6`, atenção-vermelho `#a2281a` (fundo `#fbe3df`), atenção-âmbar `#8a5a00` (fundo `#fbefcf`). Fonte do sistema (`system-ui, "Segoe UI", Roboto, sans-serif`). Sem logo, sem linha "feito por docente".
- WCAG 2.1 AA: contraste, navegação por teclado (abas com `role="tablist"` e setas), foco visível, cada gráfico com tabela equivalente.
- Gráficos no padrão Storytelling with Data (spec seção 7a): título-mensagem à esquerda, subtítulo cinza, cinza para contexto e verde para foco, rótulo direto (sem legenda), sem grade/borda/fundo/3D/pizza.
- Commits pequenos, mensagens em inglês no formato Conventional Commits.

## Review Focus

1. Log exportado em inglês ou com data `dd/mm/yyyy` (4 dígitos) ou sem segundos — deve ler; formato desconhecido deve dar mensagem clara em português, nunca tela branca. Teste em Task 1.
2. Arquivo errado no campo errado (conclusão carregada como log e vice-versa, ou Excel `.xlsx`) — mensagem que diz qual arquivo é esperado e como exportar. Teste em Task 1 e Task 2.
3. Nome no log diferente do nome na conclusão (espaços extras, maiúsculas) — casar por nome normalizado (trim, espaços colapsados, minúsculas, sem acento). Teste em Task 2.
4. Turma com 1 estudante, ou período de 1 semana, ou estudante com acesso só no último dia — sem divisão por zero, medianas corretas. Teste em Task 3 e Task 4.
5. Mesmo log carregado duas vezes, ou duas turmas com o mesmo nome — não duplicar; avisar e substituir. Teste em Task 7 (`addClass`).
